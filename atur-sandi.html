MONITORING DAL APP

Atur kata sandi & pengaturan dashboard

1. Buka kunci

Pakai kata sandi saat ini, atau kunci pemulihan bila lupa kata sandi.

2. Ganti kata sandi

File kunci.json sudah terunduh. Pasang ke dashboard:

  1. Buka GitHub → DASHBOARD-APP → folder data → Upload files (masuk dengan akun Edward587-cyber).
  2. Tarik file kunci.json yang barusan terunduh ke halaman itu (nama file harus persis kunci.json).
  3. Klik Commit changes. Sekitar 1 menit kemudian kata sandi baru berlaku.

3. Kunci pemulihan

Simpan di tempat aman (mis. catatan pribadi / pengelola kata sandi). Kunci ini dipakai bila kata sandi lupa, dan tidak berubah walau kata sandi diganti.

4. Pengaturan kontrak (opsional)

Untuk menambah kontrak baru (mis. tahun 2027), API key, atau ID spreadsheet. Ubah teks lalu buat file config.enc baru dan unggah ke folder data seperti langkah 2.

Kembali ke dashboard.
